Dokumentasi Sistem PPP UMS

Automasi Ekosistem Hebahan Geran
Efficiency via Google App Script

⚡ Zero Manual Entry

Data dari Google Form diproses secara masa-nyata (Real-time) ke pangkalan data laman web tanpa intervensi manusia.

📊 Smart Priority

Sistem menyusun geran berdasarkan 'Deadline' terdekat secara automatik menggunakan algoritma sorting.

🎨 Dynamic UI

Paparan web berubah mengikut status tarikh tutup (Color-coded indicators) bagi memudahkan penyelidik.

Aliran Kerja Sistem
Bagaimana Automasi Berfungsi?
1

Input Data Terpusat

Staf memasukkan maklumat geran melalui Google Form yang mempunyai validasi data (Required fields) untuk mengelakkan ralat maklumat.

2

Pemprosesan App Script

Skrip bertindak sebagai 'engine' yang mengira baki hari: $Hari = Tarikh Tutup - Tarikh Semasa$. Jika geran telah luput, ia akan diasingkan secara automatik.

Kritikal Baki < 3 hari (Warna Merah - Amaran)
Aktif Baki 4 - 30 hari (Warna Jingga)
Baru Baki > 30 hari (Warna Hijau)
3

Sinkronisasi Laman Web

Data dihantar ke JSON endpoint atau API laman web PPP UMS. Laman web memaparkan jumlah geran aktif secara dinamik (Contoh: "Terdapat 5 Geran Aktif Hari Ini").

Integriti Fail & Lampiran

Setiap hebahan dijamin mempunyai dokumen sokongan yang disimpan secara sistematik dalam Cloud Storage (Google Drive) yang dipautkan terus ke paparan web.

🖼️ Poster Visual

Maksimum 5 fail (10MB/fail) untuk visualisasi maklumat yang jelas.

📄 Garis Panduan

Dokumen PDF rasmi untuk rujukan kriteria kelayakan penyelidik.

Uji Kecekapan Sistem
